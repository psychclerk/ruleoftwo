        How to Use This Learning Tool

        Progressive Disclosure Method

        This tool uses the "Rule of Two" to help you learn psychiatric diagnosis systematically:

        1. Start with symptoms: Reveal the two key symptoms for each condition
        2. Then signs: Reveal the two characteristic physical examination findings
        3. Then investigations: Reveal the two essential diagnostic tests
        4. Finally, the answer: Confirm the diagnosis and specialty
